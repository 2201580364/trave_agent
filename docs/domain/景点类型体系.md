# 景点体验类型标签体系

> **来源**：产品文档附录 C。属「硬事实」规范，数据库 `category` 枚举以此为准。

## 9 类标签

| 类型 | 说明 | 例 |
|---|---|---|
| 自然山水 | 以自然景观为主 | 西湖、九寨沟、黄山 |
| 古镇人文 | 历史街区、古镇村落 | 乌镇、南浔、宽窄巷子 |
| 寺庙祈福 | 宗教文化场所 | 灵隐寺、普陀山 |
| 城市观景 | 城市地标、观景台 | 东方明珠、南山一棵树 |
| 博物馆 | 展览、科普类 | 故宫博物院、陕西历史博物馆 |
| 美食街区 | 以美食为主的街区 | 回民街、户部巷 |
| 网红打卡 | 以拍照出片为主 | 网红咖啡馆、装置艺术 |
| 亲子乐园 | 适合儿童的游乐场所 | 迪士尼、长隆 |
| 演出演艺 | 演出、show 类 | 印象系列、相声 |

## 使用约束

- 数据库字段：`category ENUM('自然山水','古镇人文','寺庙祈福','城市观景','博物馆','美食街区','网红打卡','亲子乐园','演出演艺')`。
- 单值枚举（P1 每个景点一个主类型，扩展标签放 `tags JSON`）。
- P1 类型筛选（功能 #4）按此 9 类筛选；P2 起做同质化检测（如一天内 3 个寺庙）。
