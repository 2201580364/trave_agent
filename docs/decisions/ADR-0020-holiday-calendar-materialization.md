# ADR-0020：版本化节假日历展开为 O05 日期例外

状态：已接受（M1 / Gate 7）

## 背景

“周一闭馆，法定节假日开放，闭馆顺延至节后第一天”不能由固定星期闭馆和少量手工日期例外稳定表达。每年节假日和调休安排由官方公告确定，不能由运行时猜测。

## 决策

- 增加版本化的中国大陆法定节假日历目录，年度版本包含节假日连续日期范围和公告说明。
- 管理员在 O05 页面选择节假日历、开放时间、最晚入馆时间和是否顺延；系统将策略展开为候选 `open_override` 与 `closed` 日期例外。
- 展开的每条记录继续走现有来源有效性、逐项人工核验、Revision 审核和发布门禁，不提供绕过审核的批量通过。
- 求解器继续只消费现有 `PlaceDateException` 契约，分钟值、跨午夜表示和日期例外优先级不变。
- 具体日期例外优先于生成策略，官方特殊安排通过新增年度日历版本或单日覆盖处理。

## 取舍

M1 选择“物化为日期例外”而不是立即引入复杂的运行时节假日策略实体，以保持 Projection、求解器和历史快照兼容。年度日历更新是受控数据变更，适合后续 M2 接入审核后的外部节假日数据源。

## 验收条件

- 普通周一仍闭馆；节假日落在周一时预览开放；节后自然日预览闭馆。
- 连续多天节假日只生成唯一日期记录，重复生成具有幂等性。
- 调休工作日不会自动打开或关闭，具体公告差异可用单日例外覆盖。
