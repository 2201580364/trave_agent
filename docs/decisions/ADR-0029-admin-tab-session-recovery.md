# ADR-0029：管理端标签页会话恢复

- 状态：已接受（2026-09-18 用户明确选择保留 sessionStorage，避免刷新重新输入账号密码）
- 关联：OM1、S8、H3；替代 ADR-0020 中“仅内存、不使用 sessionStorage、刷新必须重新登录”的会话存储约定；其他授权边界保持。

## 决策与安全边界

管理端允许在同源 sessionStorage 保存 Bearer token，刷新后调用 `/api/v1/admin/me` 校验并恢复主体。不能仅凭本地 token 或缓存角色认定登录有效；RBAC、过期、撤销、session_version 仍由服务器判断。恢复失败清除 token 和主体，401 或退出同样清除；存储不可用时退化为内存会话。

不保存密码，不使用 localStorage、Cookie、URL、日志或跨标签广播传递 token。sessionStorage 是标签页作用域，不是浏览器关闭即可靠销毁的安全保证：浏览器恢复、复制标签页可能保留或复制会话，安全时限必须以服务器过期和撤销为准。

相对于仅内存方案，token 驻留更久，仍可被同源 XSS 读取。控制面禁止不可信 HTML 执行和敏感日志，生产外部访问仍要求 HTTPS。无新增第三方依赖，不把受控裸 HTTP 环境当作正式公网认证验收。

## 验证与重新评审

覆盖刷新 `/me` 恢复、过期/撤销失败清理、退出、存储不可用退化，以及角色事实仅来自服务端。网络失败按 fail-closed 处理，不保留已认证主体；旧请求返回不得覆盖后续退出状态。

若引入跨设备长期登录、SSO、Cookie认证或遇到会话泄漏事件，应重新评审存储、CSRF/XSS与撤销机制。部署与外部安全验收依用户本轮安排后置。
