# ADR-0026：固定场次允许开场后入场

- 状态：已接受（2026-09-15 用户明确裁决）
- 关联：H3、C2、C4、C6、S1；替代 ADR-0025 中必须完整观看及最晚入场不晚于开始的限制。

## 决策

固定场次要求开始分钟小于结束分钟；填写最晚入场时，该分钟必须严格小于结束分钟。允许最晚入场晚于开场，不再将其截断为开场时间。跨午夜沿用 0–2880 的连续分钟表示。

求解器保留一个地点一个节点及离散场次选择。沿用每场的入场规划时刻（填写的最晚入场分钟，未填写时为开场分钟），占用从入场到场次结束的时间；实际观看开始为 max(入场, 开场)，必须严格早于结束。固定场次不因剩余观看时间不足建议时长的 60% 被硬拒绝；普通景点 C2 时长比例规则保持。建议时长仍用于体验说明。

真实交通衔接、到离锚点、闭馆、天气、来源、审核与发布门禁继续执行。发布载荷原样保留来源中的场次数据，历史 Revision 与既有发布投影不改写。约束版本升为 constraints-p1-v7，目标函数不变。

## 验证

- 开场前、开场时、开场后和结束前一分钟可入场；结束时及之后拒绝。
- 审核准备度、发布载荷、数据库读取及求解器保持一致。
- 晚入场必须保留到结束的占用，后续 OD 和返程不能越界。
- 三地点两轮审核发布流程以本地业务接口和浏览器实际操作取证。
