# 用户研究

> G1 阶段产物。M1 启动前完成 5–8 次深度访谈，校准 H1–H12 中与用户认知相关的假设。

## 内容

- 研究计划（样本量、招募标准、访谈提纲）
- 竞品体验日志（小红书/携程/马蜂窝/Google Trips 摩擦点地图）
- 访谈纪要
- 结论（用户旅程地图、痛点优先级、JTBD、核心画像）
- **对 assumptions.md 的修订结果**

## 关键研究问题（摘自产品文档 11.3）

1. 做攻略的真实流程？各阶段耗时与最痛点？
2. 「选择焦虑」vs「信息碎片化」，哪个更大？
3. 什么情况下放弃自排行程改用现成攻略/跟团？
4. 对「AI 排行程」的信任门槛在哪？
5. 三个行程模式是否覆盖自述旅行风格？
6. 是否愿付费？心理价位与模式？
7. 大交通决策流程：先订票还是先做攻略？

## 结论如何影响产品（摘自产品文档 11.4）

| 发现 | 调整 |
|---|---|
| 选择焦虑比排程逻辑更大 | M2 对比/舍弃前置，M1 加同质化标记 |
| 对 AI 信任度低 | M1 强化可解释性，每步附理由 |
| 体力预算概念不直观 | 改「行程节奏：紧凑/适中/悠闲」话术 |
| 先订票再做攻略是主流 | M1 大交通前置为必填 |
