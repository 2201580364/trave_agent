## 数据边界

- Golden Case 不在运行时访问上述网页，确保测试可复现。
- `2026-08-24` 至 `2026-08-26` 是固定测试日期，不代表真实预报。
- `extreme` 天气、OD 缺失和首日抵达时间是故障注入，用于验证 C4/C5/C6。
- 景点开放分钟数是模型化快照。上线数据仍必须经过 `data_verified` 门禁。
- 交通采用带 `approximate` 标识的坐标近似；不得在报告中伪称高德真实 OD。
