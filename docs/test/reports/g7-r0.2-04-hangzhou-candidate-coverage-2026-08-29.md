## 2. 获取边界

- 使用用户已授权的高德 Web 服务 Key 进行低频真实 API 查询；Key 只从 `.env` 读取，没有进入命令输出、缓存、目录或报告；
- Git 忽略的 `var/audit/` 只保存选中的有限候选字段，不保存带 Key URL 或无界原始响应；
- 西湖音乐喷泉复用 2026-08-27 已由用户接受的高德 POI `B023B08WZ7` 和浏览器复核证据，当前目录仍统一标记 candidate，不改写原 human_verified 快照；
- 没有采集社交 UGC、OTA 评论、账号、评论全文、图片、视频、Cookie、token 或实时价格；
- 没有使用政府门户首页作为场馆事实的无限通配来源；官方运营方页面、开放时间、入口和日期例外留待 R0.2-05 逐项登记与审核。

- “小河直街”先后命中管委会和商店；收敛为“小河历史文化街区”整体 POI；
- “龙井村”命中村委会；改用“龙井村牌坊”作为仍待审核的区域代表候选；
- “运河夜游”没有稳定同名 POI；收敛为“杭州运河游船”，不伪造固定夜游事实；
- “湘湖夜游”没有充分同名 POI；收敛为“湘湖游船”，取消夜间标签。

## 5. 门禁

目录校验器强制：

- catalog 和每个地点只能是 `candidate`；
- registry/dictionary ID 与规范化 SHA-256 必须精确匹配；
- `gaode-web-service + api + staging` 对所用字段必须获准；
- candidate ID 和高德 POI ID 不能重复；
- 坐标必须位于杭州工程包络；
- area/route 必须保留“Provider point 不是地点几何”的审核标记；
- 每个候选必须保留访问点、时间规则和时长未审核标记；
- relation clue 必须引用存在的候选，且当前只能是 `unresolved`；
- coverage 文件必须是 catalog 的精确确定性投影，禁止手改汇总数。
