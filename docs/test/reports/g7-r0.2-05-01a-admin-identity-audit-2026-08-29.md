## 实现范围

- 独立 `AdminActor/AdminRole/AdminSession/AdminAuditEvent` 领域值和 SQLAlchemy 持久化；
- 标准库 `hashlib.scrypt` 密码摘要；高熵随机管理会话 token 只保存 SHA-256；
- 空 `admin_actors` 数据库的一次性环境变量引导；
- `POST/DELETE /api/v1/admin/sessions`、`GET /api/v1/admin/me`；
- 管理员创建、列表、角色替换和最小只读审计查询；
- 服务端 RBAC、operation intent、非敏感 operation digest、actor version 乐观锁；
- 角色变化递增 session version，旧会话立即失效；
- 最后一个有效 `admin_security` 移除保护；
- 登录、管理员创建、会话撤销、角色变更的成功/拒绝追加式审计；
- Alembic `0007_admin_identity_audit`，只追加 5 张表和 6 个角色目录。

## 安全边界

- 匿名/普通用户 Bearer token 不能认证为管理员；
- 初始密码、管理 token 原值、API Key、Cookie、私钥和第三方页面全文不进入审计；
- reason text 最长 500 字并拦截明显凭证词；
- 审计记录只提供查询 API，不提供编辑或删除 API；
- 管理审计保存在结构化数据库中，不随每日分级文件日志的月度 ZIP 归档清理；
- `.env` 继续由 Git 忽略，`.env.example` 只登记空变量；
- 未在本机安装或启动 MySQL/Redis，未连接或迁移服务器数据库。
