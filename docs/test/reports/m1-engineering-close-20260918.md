# M1 现有工程收尾验证（2026-09-18）

关联 H3、S8、G7-R0.2-06、OM1；本报告记录这一轮证据，不作为 M1 最终验收结论。用户明确后置部署与真实用户研究，并要求下一阶段再实现行程评分与有界优化。ADR-0028 仍为 Proposed。

## 实现与验证范围

- 管理端其余认证、管理员、审计、来源冲突、发布批次、研究快照、O17/O18 响应接入结构化响应模型；61 个管理操作的 JSON 成功响应有 schema 门禁，管理响应 TypeScript 类型由 OpenAPI 生成。用户端通用响应的全量模型迁移不在 S8-3 范围内。
- 保留 sessionStorage，经 `/me` 恢复；ADR-0029 记录用户裁决。防止旧恢复响应在退出后复活主体、旧 401 清除新登录、退出后迟到请求弹出失效通知。Vite `/admin` 重定向与生产边缘一致，修复管理首页刷新显示 base URL 提示的问题。
- 首次生成和替换生成共用持久化任务恢复：POST 前保存操作标识和原请求；刷新重放同一 intent；网络不确定或轮询超时保留请求；完成后清除。时长、到达时间和短距离按实际数值展示，不把 1 分钟伪装成 20–30 分钟。
- 详情和分享均明确标识测试天气；分享不再展示英文 fixture 文本，也不把时长向上取整为另一种游览事实。旧分享对象不重写，展示兼容旧 fixture 标记。
- worker 装配入口位于 `interfaces/generation_worker.py`，基础设施只保留注入式进程循环。任务状态和更新时间共同用于乐观写入，防止超时接管后旧执行者写回结果或失败。无新增迁移、无新增第三方依赖。
- OD 审计增加分阶段耗时、缓存命中、请求数、等待与失败数，区分求解和外部取数；未修改现有求解目标函数。

const adapter = { page: tab.playwright, reload: () => tab.reload() }

部署、HTTPS/环境锁定、远端 CI 和真实用户研究按用户安排后置。发布门禁代码修复尚未随稳定批次部署；冷缓存性能和行程质量仍有明确开放项，不能宣告 M1 Gate 7 最终通过。
