## 2. 联游与 OD 一致性

使用新审核坐标版本重建后的 42/42 严格高德 OD 给出的关键结果：

```text
飞来峰 → 灵隐寺：walking，324m，5min
灵隐寺 → 飞来峰：walking，496m，7min
西湖湖滨 → 湖滨晚间表演：walking，386m，6min
湖滨晚间表演 → 西湖湖滨：walking，386m，6min
```

这些结果与浏览器页面上观察到的点位语义一致：

- 飞来峰 1 号门与灵隐寺进口属于同一联游区域，但步行网络具有方向差异，不能把两点合并为同一个裸坐标；
- 湖滨公园代表点与音乐喷泉表演点邻近，但一个是开放区域代表点，一个是固定表演地点，仍应保留为两个节点；
- 求解器当前稳定顺序“飞来峰 → 灵隐寺”和“西湖湖滨 → 湖滨晚间表演”与真实有向 OD 更匹配。

本次复核消除了“Chrome 不可用、无法查看高德页面”的技术阻塞，并形成了可追溯的浏览器证据。项目发布责任人已在 2026-08-27 明确接受本报告中的 7 个点位口径并授权生成新审核版本。因此：

- `routing_point_kind` 继续保留现有精确语义；
- 浙江省博物馆的产品展示名和发布数据名应明确为“浙江省博物馆（孤山馆区）”；
- 新审核坐标版本为 `var/published/hangzhou-attractions-reviewed-2026-08-27-v1.json`，7 个点位均为 `human_verified`；
- 新严格 OD 版本为 `var/published/gaode-hangzhou-reviewed-2026-08-27-v1.json`，42/42 有向边均来自高德，0 fallback、0 missing；
- 2026-08-26 的候选坐标、候选 OD 和历史 TripRevision 不覆盖、不迁移、不原地重算；
- 正式 Published Snapshot 仍必须同时满足严格 OD、真实天气和内容哈希门禁，路线点审核通过不等于已经完成生产发布。
