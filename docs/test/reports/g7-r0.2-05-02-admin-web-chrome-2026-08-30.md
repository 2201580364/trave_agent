## 数据边界

首页的 72 个候选统计来自版本化候选目录；当前本地 SQLite 中 `place_revisions` 和 `place_review_tasks` 尚无可展示记录。因此本轮只验收页面结构、空态、筛选和安全边界，不把 72 个候选描述为已导入、`human_verified` 或 `published`。批量采集、Revision 导入和人工审核仍属于后续 R0.2-05-03。

## 发现与修复

- `admin-web/src/layout/AdminLayout.tsx` 的候选地点菜单标签原为乱码，已修复为“候选地点”。修复后 Chrome 快照和截图均显示正常。
- 当前 Chrome 控制能力未强制覆盖 375×812 窄屏；本报告仅记录桌面 Chrome 验收，不替代移动端截图门禁。
