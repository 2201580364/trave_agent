## 边界说明

本轮 Chrome 实例已恢复可用，并完成管理员登录、发布中心、`browser-e2e-base` Revision 详情和 Projection 准备阻断提示复核。页面显示了稳定业务原因码 `MISSING_VERIFIED_ACCESS_POINT`。该浏览器夹具的规范名称、区域和地址仍显示为问号，属于既有 fixture 编码/数据质量遗留；正式研究数据不得沿用该夹具文本。

本地数据库当前没有“`human_verified` + candidate Projection + 全部门禁通过”的待发布 Revision，页面中的可勾选批次项因此为空，不能为了验收而直接用 SQL 制造审核或发布状态。成功批次路径使用已有真实发布数据经 O09 管理 API 执行，未绕过领域 publication check；后续导入并完成人工审核的 candidate 数据后，需在 Chrome 中补一次“勾选 → 预览 → 执行”的完整操作面回归。
