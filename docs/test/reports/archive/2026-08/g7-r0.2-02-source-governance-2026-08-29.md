浏览器复核后，三个政府/开放数据入口的 `review_status` 从 `pending_browser_review` 更新为 `reviewed`，但 `decision` 继续保持 `conditional`。原因是视觉复核能够证明站点主体、栏目和协议入口真实存在，不能证明整个站点允许批量遍历，也不能替代具体场馆页面或具体数据集的许可、字段、归属和更新频率审查。

## 4. 关键安全结论

- `conditional` 来源可以进入 staging，不能直接作为 published 事实来源；
- pending/prohibited 来源必须清空允许字段和采集方式；
- 未登记 source、field、mode 或 source role 均稳定拒绝；
- registry 出现 API Key、密码、私钥或完整 Redis/MySQL 凭证时验证失败；
- 所有 58 个字段均为 `pii_allowed=false`；
- 评论全文、用户身份、图片、视频、Cookie、token 和实时库存页面副本没有采集字段；
- robots 404 不被解释为自动抓取许可；
- HTTP 200、POI 命中或地点数量达标不能越过字段级和发布门禁。
