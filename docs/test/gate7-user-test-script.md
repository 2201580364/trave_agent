# Gate 7 用户测试主持脚本

- 脚本版本：G7-USER-V1
- 对应 protocol：`m1-hangzhou-gate7-v1`
- 适用：G7-R1 形成性和 G7-R2 确认性测试

## 1. 开场和知情说明

主持人逐字说明：

> 今天测试的是产品，不是测试你。过程中可能出现无法完成或不合理的情况，这些都对我们有帮助。你可以随时暂停或退出，不会产生任何损失。我们只在约定范围内记录操作、评价和去标识化问题，不会把姓名、联系方式、票号或精确私人行程提交到项目仓库。请尽量说出你正在想什么，但不需要猜我们希望听到的答案。

确认：

```text
consent_recorded: yes / no
recording_scope: none | notes | audio | screen | audio_and_screen
withdrawal_explained: yes / no
```

未记录同意时立即结束，不创建有效 Gate 7 样本。

## 2. 测试前背景

只收集分层所需信息，不收集姓名或联系方式：

```text
- 最近两年是否自行规划过 2 天以上旅行：0 / 1 / 2–3 / 4+
- 通常如何做攻略：从零手排 / 组合现成攻略 / 基本不做
- 本次同行类型：独自/情侣 / 朋友 / 亲子/长辈
- 偏好节奏：悠闲 / 适中 / 紧凑
- 是否有真实或可回忆的杭州出行需求：yes / no
```

## 3. 任务指令

主持人只读目标，不解释按钮：

### T01–T03 建立行程

> 请把它当作你真的要去杭州。使用你愿意告诉产品的日期、到达和离开条件，选择 5–10 个你确实想去的景点，然后生成行程。

观察：首次入口、返回上一步、锚点理解、按钮禁用状态、景点确认和生成信心。

### T04 理解结果

> 请用自己的话告诉我第一天怎么走、什么时候吃饭、景点之间怎么移动，以及有没有没排进去的内容。

主持人不能主动指出午餐、晚餐、交通或未排入位置。

### T05 H3 主问题

必须在解释算法、展示专家意见或建议修改前询问：

> 如果这是你的真实杭州行程，你是否愿意用它替代自己从零手排，或者把它作为主要行程底稿？请只先回答“愿意”或“不愿意”。

记录：

```text
plan_preferred_over_manual: true | false
overall_reasonableness_score: 1..5
confidence_score: 1..5
primary_reason_code:
```

随后追问：

> 最合理的地方是什么？最不合理的地方是什么？如果只能改一处，你会改哪里？

### T06–T08 调整、历史和反馈

> 请替换一个你最不满意的景点，然后确认之前版本是否还在。最后，对一个具体安排和整体行程分别提交你的真实反馈。

观察用户是否理解新 Revision、历史只读和“安排反馈不等于景点评分”。

### T09–T10 分享边界

> 请创建一个你愿意发给朋友参考的分享，并告诉我对方能看到什么、不能看到什么。如果你收到朋友的分享，请以此为参考创建自己的行程。

该任务只验证理解和可用性。没有独立接收者、公开环境和转化事件时，不得计入 H11 分享率或获客转化。

## 4. 标准 assistance

参与者停滞超过 60 秒或明确求助时才提供：

| 级别 | 话术 | 记录 |
|---|---|---|
| 一级 | “你可以再看看当前页面是否有与你目标相关的入口。” | `assistance_level=1` |
| 二级 | 指出区域，不指出具体答案，例如“可以看看页面上方的导航区。” | `assistance_level=2` |
| 失败 | 主持人必须指出具体控件或代为操作 | `task_status=failed` |

确认性测试中，二级提示后完成不能记为 `completed_without_assistance=true`。

## 5. 结束问题

```text
1. 哪一步最费力？
2. 哪个信息最让你信任或不信任？
3. 日期和到离条件是否值得填写？为什么？
4. 你认为系统忽略了什么？
5. 你愿意在什么情况下分享这份计划？
6. 你担心分享暴露什么信息？
7. 如果明天真的出发，你还需要去其他 App 查什么？
```

## 6. 主持人收尾

- 登记未完成任务和退出原因；
- 创建独立 issue，而不是只写在自由文本；
- 对自由文本去标识；
- 不在 session 结束后补填参与者未表达的答案；
- 形成性样本标记 `study_phase=formative`，不能进入 H3 确认性分母；
- 团队 dry run 标记 `participant_role=internal`，汇总器必须排除。
