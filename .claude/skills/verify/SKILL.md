# 假设验证与复盘技能

> 工作流收尾阶段：回答「假设成立吗？失败错在哪一层？」

## 步骤

1. **执行验证**：按 [docs/assumptions.md](../../../docs/assumptions.md) 的验证方式执行（自动化测试 / 用户测试 / 埋点指标）。
2. **采集证据**：硬约束单测通过率、Golden Case、性能、用户认可率、分享率等。
3. **失败归因**：每个「未达失效判据」的假设，判断错在**数据 / 算法 / 交互**哪一层。
4. **回写登记册**：更新 `状态`（已证实/已推翻/需调整）+ `证据`，用文档中的回写模板。
5. **输出下一步**：本 Phase 该改什么、下个 Phase 的假设是否需要调整。

## 关键提醒

- 主观指标（认可率）有社会赞许偏差，务必配合客观子指标（硬约束、Golden Case）一起看。
- 结论要能回答「H3 失败到底因为数据错了、算法不够好、还是交互让用户没感受到」。
