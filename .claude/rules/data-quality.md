# 数据质量门禁规则

**适用**：任何景点/餐饮/酒店等 POI 数据的采集、结构化、入库、字段改动。

1. **字段必须带来源**：所有字段必须有 `data_source`（`gaode`/`baidu_baike`/`ctrip`/`manual`）。
2. **未校准不得进求解器**：`data_verified=1` 之前，数据不得进入求解器输入集。
3. **入库前过校验**：开放时间/闭馆日/体力/类型必须满足 [docs/domain/开放时间数据规范.md](../../docs/domain/开放时间数据规范.md) 的校验规则。
4. **改动必须带校验测试**：新增/修改字段或校验规则 → 附带对应的数据校验测试。
5. **硬事实不得由 LLM 运行时生成**：开放时间/价格/闭馆日运行时一律读 DB。
